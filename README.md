🚀 Local Development

To run this website locally on your machine:

Clone the repository:

git clone https://akhilpesala4-alt.github.io/AKHILS-repository/


Navigate into the folder:

cd AKHILS


Open in browser:
Double-click index.html or run a local server:

npx serve .
